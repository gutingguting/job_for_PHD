# job_for_PHD 预填写助手

这是 Chrome/Edge Manifest V3 本地扩展。它只在用户点击扩展图标后读取或填写当前标签页，不会点击最终提交。

## 安装

1. Chrome 打开 `chrome://extensions/`，Edge 打开 `edge://extensions/`。
2. 启用“开发者模式”。
3. 点击“加载已解压的扩展程序”。
4. 选择本目录：`E:\jobhunter\extension`。
5. 打开 `http://localhost:8420/dashboard.html#prefill` 生成配对码并在扩展中输入。

## 使用

- **导入当前已填表单**：保存当前页面中用户已经填写的非敏感字段和用人单位问答。
- **一键预填当前页面**：只填写空白且匹配明确的字段，并回读校验结果。
- 遇到冲突时回到 Dashboard 选择保留现有值或采用导入值。
- 最终提交始终由用户在招聘页面亲自执行。

## 隐私边界

扩展不申请 Cookie、密码或浏览历史权限，不读取网页存储。政府证件号、出生日期、精确住址、健康/人口统计信息、密码、验证码、CAPTCHA、声明同意和最终提交控件均被排除。
